# Release notes

One file per version, named for the version: `X.Y.Z.md` (for example `0.2.0.md`). The release
workflow puts the file for the tagged version into `latest.json`, and the update icon shows it.

- Plain sentences, a few lines. No headings, no links.
- No file for a version means the notes read "Atlas X.Y.Z".
- Never reused: a new version needs its own file.
